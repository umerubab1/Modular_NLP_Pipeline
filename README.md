# Modular NLP Text Preprocessing Pipeline
This project is a modular and reusable NLP preprocessing pipeline that cleans and prepares raw text data for machine learning tasks. It includes custom tokenization, stopword removal, and lemmatization.
## Features
- Text cleaning (lowercase, punctuation removal, etc.)
- Custom tokenization using regex
- Stopword removal
- Lemmatization (NLTK)
- Optional stemming
- Batch processing support
- CLI-based interaction system
## Technologies Used
- Python
- NLTK
- Pandas
- Regex (re module)
## How to Run

1. Install dependencies:
   pip install nltk pandas
2. Open notebook:
   Modular NLP Preprocessing Pipeline.ipynb
3. Run all cells step by step
